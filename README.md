# Анализ процесса регистрации пользователей

## О проекте

Проект посвящен анализу событийных данных процесса регистрации пользователей.

Цель — исследовать динамику регистраций, оценить скорость прохождения процесса, рассчитать ключевые метрики и определить этапы, на которых могут возникать затруднения.

## Что исследовала

В рамках проекта:

- проанализировала количество успешных регистраций;
- рассчитала среднее время регистрации;
- восстановила пользовательский путь по event-логам;
- рассчитала время прохождения отдельных этапов;
- проанализировала конверсию из старта регистрации в успешное завершение;
- определила точки остановки пользователей;
- исследовала время ответа после Submit;
- рассчитала долю повторных Submit по отдельным этапам.

## Основные результаты

- количество успешных регистраций выросло с **14 338 до 20 901** с января по июль 2024;
- среднее время успешной регистрации практически не изменилось: **6,89 → 6,84 мин**;
- конверсия в успешную регистрацию в июле составила **96,13%**;
- основной точкой остановки пользователей оказался этап идентификации;
- доля остановок на этапе идентификации снизилась с **3,01% до 2,30%**;
- наиболее длительным этапом оказалось прикрепление документов;
- доля кейсов с повторными Submit на этапе прикрепления документов в июле составила **13,08%**.

## Методология

1. Определение начала и успешного завершения регистрации
2. Обработка повторных Sign In
3. Исключение регистраций длительностью более 30 минут
4. Восстановление последовательности событий пользователя
5. Расчет длительности этапов
6. Проверка согласованности общего времени и суммы времени этапов
7. Анализ конверсии
8. Анализ точек остановки
9. Анализ времени ответа интерфейса
10. Анализ повторных Submit
